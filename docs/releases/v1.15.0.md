# PunchingShearEC2 1.15.0

Versão de referência congelada para as próximas melhorias.

## Incluído

- Código modular de cálculo, interface, importação e relatórios.
- Seleção de barras por listas e intervalos, extensão à prumada e gravação da configuração sem novas ligações.
- Grupos, parâmetros comuns, armadura longitudinal base + reforço e alturas úteis automáticas.
- Relatórios com âmbito explícito e filtro de resultados calculados e atualizados.
- Exemplos didáticos, documentação técnica e 533 testes automatizados.
- Inventário SHA-256 do código da distribuição original.

Esta publicação reorganiza a documentação e acrescenta integração contínua, sem alterar os ficheiros Python da aplicação ou dos testes.

## Limitações conservadas

A substituição da tabela de nós exige um novo conjunto. Propostas diferentes entre combinações exigem conferência de um pormenor comum. A extensão à prumada pressupõe barras verticais e nós compatíveis. A conferência visual nativa da interface continua por realizar segundo o guião distribuído.

O programa apoia a verificação técnica; não substitui a responsabilidade do projetista nem as verificações fora do seu âmbito.

## Instalação

Extraia o arquivo completo. Instale Python 3.10 ou superior, Tkinter e as dependências de `requirements.txt`; inicie por `main.py`. Consulte o README para os comandos por plataforma.

Os arquivos gerados nesta publicação têm hashes próprios. O SHA-256 do ZIP original que define a base é `510dcd38284bcbb0fa64c769edddcf62fd81d9ae28e81366b529f12290d1f70f`.
